# ADR 0040: Technical email assistance and contextual follow-ups

Status: accepted by Bernie on 2026-10-15.

The advisory assistant supports technical email setup, authentication, delivery, security and troubleshooting, including general technical explanations needed to interpret plugin results. It does not draft messages or answer unrelated questions. Short questions about what needs fixing refer to the current plugin diagnostics unless the user supplies another technical email context. Ask for missing information rather than inventing findings.

Keep local scope screening supplementary to structured model validation, not an exact-keyword requirement for valid follow-ups. Reconsider previously declined user questions under the corrected gate, but omit declined assistant replies and unrelated history. Report history truncation only for actual size/window limits. Current credential-free evidence supersedes historical answers.

Observed facts remain server-generated. Select relevant evidence sections instead of repeating the entire snapshot on every answer. Include fixed diagnostic interpretation and remediation guides, never raw diagnostic/provider text. Technical explanations and proposed steps are advisory, not observed facts or executed actions. Existing authentication, consent, encryption, quotas, retention, diagnostic confirmation and read-only MCP boundaries remain unchanged.
